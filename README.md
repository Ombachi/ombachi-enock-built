# Health Systems Architect

Create a clean, modern personal website for Ombachi Enock, a Medical Laboratory Scientist, Laboratory Manager at Mount Kenya University, founder of Litu Diagnostics, and health systems / climate-health / diagnostics professional. The website should feel credible, premium, human, and easy to navigate, with a minimalist editorial style, strong typography, and subtle animations.

Site goals:

Showcase professional identity, expertise, projects, principles, and contact details

Position him as a laboratory systems builder, health-tech innovator, educator, and climate-health thinker

Make it easy for employers, collaborators, and partners to understand his value in under 30 seconds
